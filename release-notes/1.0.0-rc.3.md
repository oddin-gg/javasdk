# Java SDK 1.0.0-rc.3

The third release candidate of the Java SDK 1.0. It adds the clock flag of the match scoreboard; nothing else changes. Everything in the [1.0.0-rc.1 notes](https://github.com/oddin-gg/javasdk/blob/main/release-notes/1.0.0-rc.1.md) and the [1.0.0-rc.2 notes](https://github.com/oddin-gg/javasdk/blob/main/release-notes/1.0.0-rc.2.md) still applies.

```xml
<dependency>
  <groupId>gg.oddin.oddsfeed</groupId>
  <artifactId>odds-feed</artifactId>
  <version>1.0.0-rc.3</version>
</dependency>
```

## New

- **Is the clock running?** `Scoreboard.getClockRunning()` (`Boolean`) says whether the in-game clock of a match runs: `true` while it runs, `false` while it stands (a pause within a period, between periods, before the start, after the end), `null` when unknown. It is read from the scoreboard of `odds_change` feed messages and of the match summary from the API. When a newer status arrives without a scoreboard (for example once the match has ended), the other values of the previous scoreboard are kept, but `getClockRunning()` returns `null`, because the flag describes the clock now. Never read `null` as `false`. The attribute is part of [oddsfeedschema v1.2.0](https://github.com/oddin-gg/oddsfeedschema/releases/tag/v1.2.0); eHockey sends it. 0.0.61 has the same flag, and this release is compatible with it.
