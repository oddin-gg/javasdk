# always the exact list - for review, and for the release notes.
#
#   kind | type or member | reason                       (fields separated by " | ")
#
# gone        a public type or member 0.0.58 had that is not here: internal, dropped with the schema,
#             or arriving with a later part of the rewrite
# added       a public type or member 0.0.58 did not have
# signature   a member whose generic signature changed on purpose; the third field is the new one
# supertype   a type whose superclass changed on purpose; the third field is the new one. Members
#             count where a caller finds them, declared or inherited, so a getter that moved between
#             a class and its superclass is not a difference
# deprecated  a member deprecated here that 0.0.58 did not deprecate
#
# Types are internal names relative to com/oddin/oddsfeedsdk/; members add ".name descriptor".
